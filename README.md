Hello, Welcome to the guts of my personal website!

The site is served by GitHub Pages from `index.html`, which is a Claude Design (`.dc.html`) page rendered in the browser by `support.js`.

- `_ds/` holds the design system (tokens, fonts, styles). `.nojekyll` is required so GitHub Pages publishes this underscore-prefixed folder.
- `assets/` holds images, videos, 3D models, and PDFs (including `Resume.pdf`).
